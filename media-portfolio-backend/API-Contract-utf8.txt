1.3 Authentication
JWT bearer tokens. Access token lifetime: 1 hour. Refresh token lifetime: 30 days. Public endpoints (marked “Public” below) require no Authorization header. All others require a valid, unexpired admin access token or return 401.
1.4 Response Envelope
Every response, success or failure, uses one of these two shapes. No endpoint returns a bare array or bare object.
// Success
{
  "isSuccess": true,
  "timestamp": "2026-08-14T10:00:00Z",
  "data": { ... } | [ ... ],
  "meta": { "page": 1, "pageSize": 20, "totalCount": 47 } // present only on paginated list endpoints
}

// Failure
{
  "isSuccess": false,
  "timestamp": "2026-08-14T10:00:00Z",
  "data": null,
  "errors": [
    { "code": "FIELD_VALIDATION_FAILED", "field": "phone", "message": "Phone number is required." }
  ]
}

2. Media Upload Flow (Cloudflare Stream & Images)
Raw video/image bytes never pass through this API. The dashboard uploads directly to Cloudflare; this API only brokers the upload URL and records the result. Both steps below are Admin-only.

Response `data`:

8. Analytics

Admin-only, paginated. Returns the same counters already present on `GET /admin/videos` (§4.2) — this endpoint exists as a dedicated, sortable view (`?sortBy=viewCount|whatsAppClickCount|formSubmissionCount`) for the dashboard's analytics screen, rather than a different data shape.
9. Health
GET  /health
Public, unversioned (`/health`, not `/api/v1/health`). Returns 200 with `{ "status": "ok" }` if the database is reachable.
10. Versioning Policy
All routes are prefixed `/api/v1`. A breaking change to any existing route's request/response shape, status code, or error code requires a `/api/v2` route rather than modifying `/v1` in place, once the frontend repo is building against it. Additive, backward-compatible changes (new optional field, new endpoint) may be made within v1 but must update this document's version number and be communicated to the other repo's developer before being relied upon.
